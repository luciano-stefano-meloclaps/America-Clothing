# ⚡ INICIO RÁPIDO

## ¿Primera vez? Esto es todo lo que necesitas:

### 1. **Windows** 
```bash
docker-setup.bat
# Selecciona opción 1
```

### 2. **Linux/macOS**
```bash
docker-compose up --build
```

### 3. **Abre en el navegador**
- Frontend: http://localhost:3000
- API: http://localhost:5000
- Swagger: http://localhost:5000/swagger

### 4. **Login con:**
```
Usuario: luciano.admin
Contraseña: admin123
```

---

## Comandos Útiles

```bash
# Parar todo
docker-compose down

# Ver logs
docker-compose logs -f

# Limpiar todo (incluyendo BD)
docker-compose down -v

# Reiniciar
docker-compose restart
```
